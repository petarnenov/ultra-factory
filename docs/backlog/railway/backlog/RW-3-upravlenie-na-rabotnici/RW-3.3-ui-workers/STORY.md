# RW-3.3 · Стори: UI екран „Workers“

**Като** оператор **искам** в Settings → Workers да виждам работниците със статус и да добавям/премахвам с диалог, **за да** управлявам капацитета без Railway конзола.

**Оценка:** 1.5–3 чд. **Зависимости:** RW-3.2, RW-2.4.4. Прочети `DESIGN.md`; ползвай `components/ui/*` (shadcn).

| Таск | Име | чд |
|---|---|---|
| RW-3.3.1 | Списък с статуси, прогрес и грешки | 0.5–1 |
| RW-3.3.2 | Диалог „Добави работник“ (форма, валидация, секрети) | 0.5–1 |
| RW-3.3.3 | Диалог „Премахни“ с активни сесии и потвърждение по име | 0.5–1 |

**Критерии за приемане**
- [ ] Статусите се обновяват без reload (polling на `GET /hub/hosts` на 5 s докато има provisioning/removing, иначе 30 s).
- [ ] Секретите в формата никога не се показват след submit и не се логват.
- [ ] Екранът е наличен само при `isWebBuild` (в Electron Remote hosts остава както е).
